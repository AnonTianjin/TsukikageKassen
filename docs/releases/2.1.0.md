# 2.1.0 · 队伍商店、读条拆弹与加时赛

## 新增

### 队伍商店（shop）
- 两队各一个商人 NPC：村民，无敌、无 AI、静音、不推动、不受伤，默认落在大厅出生点。
- 27 格商店界面，右键商人或 `/taketori shop`（等价 `/taketori buy`）打开，商品按队伍摆放。
- 商人位置跟随大厅：`shop.npc.<red|blue>.world` 留空取大厅出生点所在世界，坐标全 0 取大厅出生点坐标。
- `/taketori shop setnpc <red|blue>` 把该队商人挪到当前位置，坐标立刻写回 `config.yml`。
- 看护任务每 10 秒跑一次，NPC 被杀或区块重载后自动补回，孤儿 NPC 一并清掉。

### 拆弹钳（红队）
- `shop.defuse-clipper.cost`（默认 30 分），`shop.defuse-clipper.max-per-player`（默认每人 2 把）。
- 背包里带着它拆包，读条从 10 秒缩到 6 秒；死亡即清空背包里的钳子，购买额度不退。

### 地雷（蓝队）
- `shop.land-mine.cost`（默认 40 分），`shop.land-mine.max-per-team`（默认每队 2 枚）。
- 右键埋成石质压力板，有人进入 `trigger-radius`（3 格）引爆，`kill-radius`（5 格）内在册玩家直接死亡。
- 爆炸零伤害、不破坏方块、不点火。

### 加时赛（overtime）
- `overtime.enabled` / `overtime.duration-seconds`（默认 60）/ `overtime.kill-score`（默认 1）。
- 时间到双方都没达标 → 队伍比分清零（个人分与击杀保留，结算播报照常）+ 30 秒投票
  （`/taketori overtime`）→ 60 秒纯 PVP 比人头；加时开始后包点收掉、占点关闭，只算人头。
- 任一队全员同意即开打；某队已无人时一人投票即通过；窗口到期没通过按「防守方守住」结算。
- 记分板多一行「加时人头: 红 N : 蓝 M」，平局算平局。

## 变更

### 炸弹重做（bomb）
- 包点激活后换成 TNT（原来是拉杆），从连点改成 CS 式读条：红队站进 4.5 格内左键开始，右键取消。
- 空手 `bomb.defuse-seconds-bare`（10 秒），背包里带着拆弹钳 `bomb.defuse-seconds-clipper`（6 秒）。
- 离开范围、死亡、掉线、换队都会中断；`bomb.reset-seconds`（7 秒）内没人接手则进度归零，只提醒红队。
- 拆开 → 红队直接获胜；`bomb.defuse-time-limit-seconds`（110 秒）没拆完 → 蓝队守住：
  蓝队 +`blue-keep-score`（200）、红队 +`red-consolation-score`（50），基地随后开放。
- 包点相位化：自由时段（`bomb.activation-delay-seconds`，40 秒）→ 拆弹窗口 → 抢基地，
  记分板显示「包点: 未激活 / 拆除中 Ns / 蓝队守住」。
- 没设包点的场地不进相位机，仍按「基地开放延迟 + 分数」判胜负。

## 升级注意
- `config-version` 从 11 升到 12，老配置启动时自动补默认值，不用手改。
- 迁移会删掉退役键 `bomb.defuse-clicks` 并打一条警告；其余老键原样保留。
- 场地不用重划：`arenas.yml` 的包点坐标沿用，只是从「拉杆」变成「TNT + 读条」。
- 构建基线一起抬了：Paper 26.1.2 + Java 25，jar 内 `api-version: 26.1.2`，
  服务端低于该版本会拒绝加载，升级服务端后再换 jar。
- 插件版本号 2.1.0。

## 已知事项
- `overtime.kill-score` 目前不参与计算，加时人头固定每次击杀 +1。
- 加时投票窗口是 30 秒硬编码，不在配置里。
- 拆弹钳额度按购买次数计，死亡只清道具不退额度。
- 数据目录名在 1.7.0 那次改成 `plugins/TsukikageKassen/`。如果当时没改名，现在仍然要改，
  否则角色绑定、战绩、场地、月面模板全部读不到。

## 构建产物
`TsukikageKassen-2.1.0.jar`，大小与 SHA256 见本次 GitHub Release 资产页。
目标服务端 Paper 26.1.2，Java 25，jar 内 `api-version: 26.1.2`。
jar 不进仓库：请从 GitHub Release 资产下载，或本地 `./gradlew build` 生成于 `build/libs/`。
上面的大小与校验值指的是 Release 上那个资产；用当前代码重建不会逐字节相同，别拿它当回归基线。
