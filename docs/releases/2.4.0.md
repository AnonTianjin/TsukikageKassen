# 2.4.0 · 武器技能三槽化与独立被动

每把武器从「4 个按键槽 + 多模式」改成「3 个技能 + 1 个被动」：左键回到原版普攻、右键只放一个主动技能、
双击潜行只放移动技能，被动单独成段。

## 破坏性变更

- **槽位**：`left` / `right` / `sneak`（双击潜行）。`shift-right` 改名为 `sneak`，`q` 整个下线。
- **多模式下线**：`modes` / `default-mode` 失效，8 把多模式武器（陨星锤、金棒、月镜、壁垒令旗、冰棘鱼、
  大太刀、铁锁、影镜）合并为单套三技能；`mode_switch` / `equip_switch` / `special_shot_toggle` 三个类型删除。
- **被动落位**：新增武器顶层 `passive:` 段，不再占用 `left` 槽；把被动写进按键槽会被校验点名。
- **左键**：近战武器左键恢复原版普攻（伤害由 `attributes.attack-damage` 决定），不再取消原版伤害；
  弓的左键改为主动技能「瞄准射击」。
- **右键**：仅当 `right` 绑定技能时才拦截；弓 / 三叉戟留空即走原版拉弓 / 投掷。

## 新增

- **被动机制**：`PassiveDef`（core，含数值钳制）+ `PassiveApplier`（常驻属性，换手/进服/重载刷新）+
  `PassiveListener`（命中结算）。常驻侧支持移速 / 抗性 / 跳跃，命中侧支持易伤 / 破甲 / 减速 / 吸血 / 击退 /
  附加伤害；近战与箭矢分别用 `chance` / `throw-chance` 控制概率。
- **三叉戟忠诚**：`weapons.yml` 支持 `enchantments:`，冰棘鱼配 `loyalty: 3`，投掷后自动回手；
  附魔等级自动夹到原版上限，Lore 不出现原版附魔行。
- **指令**：`/taketori sneak`（等价于旧 `/taketori f`），手动触发移动技能做自检。
- **假人技能回归**：`tools/skill-smoke.sh` 起真实 Paper + mineflayer 假人，逐把武器验证右键 / 双击潜行冷却、
  普攻命中、减速类被动、忠诚回手，共 61 项断言。
- **离线断言**：`PassiveRulesTest`（被动参数钳制与概率回落）、`CooldownManagerTest`（冷却表键与过期回收）。

## 变更

- **冷却表**：键改为 `record Key`（玩家 + 武器 + 槽位），存储改两层 Map，玩家退出清理 O(1)，
  过期条目在查询时惰性回收，`size()` 只统计仍生效的条目。
- **`weapons.yml` 20 把武器全部重写**：每把 3 个技能 + 1 个被动，数值与角色定位保持一致
  （例：陨星锤 = 破甲被动 + 砸地冲击 + 火箭跳；镇魂铃 = 易伤被动 + 月华庇护 + 疾行；
  云丝 = 减速被动 + 丝网陷阱 + 闪身）。
- **武器编辑器**：去掉模式页，只编辑三槽与被动；`/taketori skills` 改为展示三技能 + 被动。
- **按键**：F 键只拦截「把插件武器换到副手」，不再触发技能；`input.shift-right-trigger` 只接受 `double-sneak`。

## 升级注意

- **`weapons.yml` 不会自动迁移**：旧文件的 `shift-right` / `q` / `modes` 会失效，启动时若检测到旧结构会给出提示。
  正确处理是：备份后删除 `plugins/TsukikageKassen/weapons.yml`，再 `/taketori reload` 取新模板。
- `config.yml` 的 `config-version` 会自动升到 13；旧 `shift-right-trigger` 写法会被收回 `double-sneak`。
- 旧武器物品上的 `mode` PDC 会被直接忽略，不需要重新发放物品。
- 依赖「模式」的第三方文档/宏需要同步：一把武器现在只有三个按键动作。
