# 2.2.0 · 角色技能表与商店修补

## 一句话

九名角色的技能表补上了（`docs/characters.md`），商店与商人 NPC 的几个坑也一起修掉。

## 新增

- **角色技能表** `docs/characters.md`：每名角色的血量 / 移速 / 武器，每把武器按模式列出
  按键、技能类型、冷却与关键数值，末尾附技能类型索引。
  由 `tools/gen-character-table.py` 从 `characters.yml` + `weapons.yml` 生成——
  改完数值重跑一次即可，不要手改文档。
- `characters.yml` 头注释补上 id 与显示名的对应关系。

## 变更

- `docs/shop-and-bomb.md`：购买流程补「背包满买不了」，地雷补落点限制
  （场地内、非包点、非已有地雷、非实体方块）。

## 修复

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 右键商人没反应，反而开了原版空交易界面 | 村民的原版交互走 `mobInteract`，服务端派发 `PlayerInteractEntityEvent`，而插件只监听了 `PlayerInteractAtEntityEvent` | 两个事件都接，共用同一套点击处理，先取消事件再开自绘界面 |
| 商人看着像野生村民 | 只设了名字 | 红队铁匠 / 蓝队工具匠 |
| 界面亮着却买不了（或反过来） | 界面按「背包里现有几把钳子」判，内核按「买过几次」判，地雷又是第三套账 | 界面不再自己数，直接调 `GameRoom.clipperDenyReason` / `landMineDenyReason` |
| 地雷能盖住包点、盖住别的地雷、盖在场外 | 落点没做校验 | 四道守卫：场地内、非包点、非已有地雷、可放置方块 |
| 背包满时扣了分却没拿到东西 | `addItem` 失败后静默丢进虚空 | 先要求腾出一格；真溢出就掉在脚下，且掉落前抹掉 `land_mine` / `defuse_clipper` 标记 |
| 关掉商店后地图上还留着商人 | 只处理「开着」的分支 | `shop.npc.enabled: false` 时清理残留 |
| 配置的世界没加载时商人生成在错误世界 | 回落到了大厅世界，还会顺手删掉真商人 | 这一轮直接跳过 |

## 兼容性

- 配置版本不变（`config-version: 12`），无需迁移。
- 角色 id、武器 id、存档与玩家数据都不受影响。
- 构建基线仍是 Paper 26.1.2 + Java 25。
