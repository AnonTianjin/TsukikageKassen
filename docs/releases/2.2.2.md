# 2.2.2 · 队伍识别、角色选择与 moonmap 导入提示

## 一句话

补上队帽（红/蓝一眼分敌我）、没选角色不再被静默跳过、加时投票超时改判平局，
moonmap 导入失败时直接告诉你地图该放哪。

## 新增

| 项 | 说明 |
| --- | --- |
| 队伍头盔 | 开局与重生发 `LEATHER_HELMET`：红队深红「进攻方」、蓝队靛蓝「防守方」，不可损坏，隐藏附魔/属性/染色条目。与出生增益解耦，`spawn.buff.enabled=false` 也照发 |

## 变更

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 加时投票超时（30 秒内没谈拢） | 防守方（蓝）获胜 + 给守方保底分 | 判平局，双方不加分 |
| 玩家没选角色就进房（补位 / 开局） | 静默跳过，不发光不发提示 | 提示「先选一个角色」并直接打开角色菜单 |

`overtime.enabled: false` 的场地仍按「时间到 → 防守方守住即胜」结算，行为未变。

## 修复

| 问题 | 处理 |
| --- | --- |
| moonmap 导入失败只回一句「不是可用的世界文件夹」 | 追加：插件实际查找的完整路径、该路径是否存在的判定，以及当前容器里可导入的世界名（最多 8 个） |
| 上一轮的「玩家 ↔ 角色」绑定跨重启保留，导致按旧角色发装备 | 启动时清空绑定并打日志「已清除 N 条上局角色绑定…」；隐性标签保留 |

## 兼容性

- 配置版本不变（`config-version: 12`），无需迁移；没有新增配置键。
- 角色 id、武器 id、存档与玩家数据都不受影响。
- 构建基线仍是 Paper 26.1.2 + Java 25。
