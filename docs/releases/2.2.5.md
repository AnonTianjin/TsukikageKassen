# 2.2.5 · 建房与 moonmap 失败时的诊断补全

只动失败路径的提示和一处日志，不涉及玩法。

## 改动

| 场景 | 之前 | 现在 |
| --- | --- | --- |
| 建房时世界加载不出来 | 提示「服务器未能加载世界」 | 提示「世界加载失败，清理残留目录后请重试」 |
| `moonmap load` 编辑世界创建被拒 | 只给管理员一句「服务器未能加载世界」 | 日志打出 `[moonmap] 服务器未能加载编辑世界 <名>（WorldCreator 返回 null）`，创建改走 `createWorldCleanly()`（失败重试一次） |

## 为什么改

服主在控制台看到 `WorldCreator 返回 null` 才能判断是「创建被拒」（多半是残留目录没清干净、或世界重复），
而不是「复制模板失败」——这两个原因的处理方式完全不同。建房那条则把处理动作直接写进提示里。

## 兼容性

- 配置、命令、权限、数据格式都没变，无需迁移。
- 构建基线仍是 Paper 26.1.2 + Java 25。
