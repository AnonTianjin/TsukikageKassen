# 2.4.1 · 商店 NPC 进驻对局房间与文档校正

对局房间（由模板拷贝出来的世界）里现在也有商店 NPC，顺手修掉大厅商人被看护任务重复生成的问题；
同时把 2.4.0 遗留的过时文档与配置表一并校正。

## 新增

- **对局内商店 NPC**：`ShopNpcManager` 新增 `spawnForRoom(GameRoom)` / `removeRoomNpc(GameRoom)`，
  开局按场地红 / 蓝出生点各生成一名商人，对局结束或房间清理时移除；与大厅商人互不影响。
  接线在 `GameRoom.startPlay()`（非战国模式）与 `stopComponents()`。

## 修复

- **看护任务重复生成商人**：`ensureAlive` 每 200 tick 在主线程检查，区块未加载时 `Bukkit.getEntity` 返回 null
  会被误判死亡并补一只。现在先判断商人所在区块是否已加载，未加载直接跳过；且不再提前清除 UUID，
  避免区块加载后出现两只。
- **大厅两名商人坐标重合**：两队配置坐标都为 0 时重叠在出生点，现按队伍沿 z 轴错开 1.5 格（红 -1.5 / 蓝 +1.5）。
- **NPC 名称与去留**：自定义名支持 `&` 色码（此前只认 `§`）；补 `setRemoveWhenFarAway(false)`，走远不再被服务端回收。
