# 2.0.1 · CS 式拆包攻防

## 新增

### 包点（bomb）
- `/taketori arena setbomb` 用站位指定方块，`/taketori arena delbomb` 移除。
- 开局把包点方块换成拉杆，进攻方连点 `bomb.defuse-clicks` 下（默认 10）即胜。
- 中途停手到 `bomb.reset-seconds`（默认 7 秒）进度复位，并通知进攻方还剩多少。
- 包点方块禁止破坏，左键也拦下；方块被插件以外的方式改掉会回补成拉杆。
- 场地没有包点时，对局回到纯计分判定。

### 不对称计分
- `match.defender-score-to-win`：防守方目标分。
- `match.attacker-score-multiplier`：进攻方得分倍率，默认 1.0。
- 记分板按各自目标显示进度。

### 回程落点
- `lobby.return-to-entry`（默认开启）：对局结束把参赛者送回进房间前所在的位置。
- 原位置所在世界在对局期间被卸载时，回落到大厅出生点。

## 升级注意
- `config-version` 从 10 升到 11，老配置启动时自动补上新增的键，不用手改。
- 迁移不改写 `match.score-to-win`。那个值可能是你自己调过的，直接覆盖会悄悄改变对局节奏，所以进攻方目标分沿用原值，只补新增键。
- 插件版本号 2.0.1。

## 已知事项
- 数据目录名在 1.7.0 那次改成 `plugins/TsukikageKassen/`。如果当时没改名，现在仍然要改，否则角色绑定、战绩、场地、月面模板全部读不到。
